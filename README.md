# 📊 E-commerce Transaction Analysis using Hadoop Ecosystem



## 📌 Project Overview

In today's data-driven world, e-commerce platforms generate massive volumes of transactional data daily. Traditional systems are not efficient enough to process such large-scale datasets.

This project presents a **scalable Big Data pipeline** using the Hadoop ecosystem to efficiently process and analyze e-commerce transaction data.

🔍 The system transforms raw data into actionable insights, such as:

- Product-wise total revenue  
- Top-performing products  
- Sales trends analysis  

---

## 🎯 Objectives

- Store large datasets using HDFS  
- Process data using MapReduce (Python)  
- Perform analytical queries using Hive  
- Understand distributed data processing  
- Generate insights from raw transaction data  



---

## ⚙️ Technologies & Tools

- **HDFS** – Distributed Storage  
- **MapReduce** – Parallel Processing  
- **Hive** – SQL-based Analysis  
- **Python** – Mapper & Reducer  
- ** Cloudera** – Execution Environment  
- **ChatGPT** – AI Assistance  

---

## 📊 Dataset Information

The dataset contains e-commerce transaction details:

| Attribute | Description |
|----------|------------|
| OrderID  | Unique order ID |
| Product  | Product name |
| Category | Product category |
| Price    | Price of product |
| Quantity | Quantity purchased |
| Date     | Purchase date |

---

## 🔄 Workflow

1. Upload dataset to HDFS  
2. Process data using MapReduce  
3. Store processed output in HDFS  
4. Analyze data using Hive  
5. Generate insights  

---
